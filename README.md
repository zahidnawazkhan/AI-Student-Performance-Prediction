# AI Student Performance Prediction

## About the Project

This project is a simple Machine Learning system developed to predict a student's final exam marks using study hours, attendance percentage, and previous exam marks.

The project was developed as a Computer Science learning project to explore Python programming, data analysis, machine learning, and data visualization.

## Features

* Predicts final exam marks
* Uses study hours, attendance, and previous marks as inputs
* Uses Linear Regression for prediction
* Calculates Mean Absolute Error (MAE)
* Generates a graph showing study hours versus final marks

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Tkinter

## Machine Learning Model

The project uses a **Linear Regression** model.

The current dataset contains 16 sample student records. The data is **synthetic and created for educational purposes**.

For one test run, the model produced a Mean Absolute Error (MAE) of approximately **0.66 marks**.

## Example Result

### Input

* Study Hours: 5 hours/day
* Attendance: 85%
* Previous Marks: 75%

### Prediction

* Predicted Final Marks: **73.76%**
* Performance Level: **Very Good**

## Project Files

* `main.py` — Basic student performance prediction application
* `ml_model.py` — Machine Learning prediction model
* `study_hours_vs_marks.png` — Graph generated by the ML model

## Limitations

This project uses a small synthetic dataset for educational purposes. Its predictions should not be considered a reliable assessment of real students.

A larger and properly collected real-world dataset would be required to develop a more accurate prediction system.
