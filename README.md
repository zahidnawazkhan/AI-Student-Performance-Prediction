# AI-Based Student Performance Prediction System

## About the Project

This is a Python-based student performance analysis and prediction project developed by a Class 12 Computer Science student.

The system takes student academic marks and daily study hours as input and analyzes academic performance.

## Features

- Calculates average marks
- Evaluates student performance
- Considers daily study hours
- Provides a simple performance prediction
- User-friendly graphical interface

## Technologies Used

- Python
- Tkinter
- Basic Data Analysis
- Conditional Logic

## Purpose

The purpose of this project is to demonstrate how programming and basic data analysis can be used to analyze student academic performance.
